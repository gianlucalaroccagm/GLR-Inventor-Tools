0. What's New in Version 5.0

This section summarizes the main enhancements introduced in GLR Advanced BOM Viewer v5.0. It is intentionally separated from the base user guide so that new capabilities are immediately visible while preserving the original v4 documentation layout.

0.1 Real-Time Sync & Non-Modal Stability (Always-On Form)

  • Always-On, Non-Modal Operation: The BOM Viewer now runs as a fully non-modal window, remaining open and interactive while you work directly in the 3D viewport. There is no need to close and reopen the form during your design sessions.
  • Live Structural & Property Updates: Adding, deleting, replacing, or suppressing components in your assembly is automatically reflected in the grid.
  • Model States Synchronisation: Switching the active Model State of the main assembly triggers an immediate background recalculation, cleanly updating quantities, parts, and properties.
  • Safe Selection Pipeline: The selection tracking system has been optimized to prevent feedback loops between the 3D viewport and the grid when performing visibility actions (Isolate, Hide, Show), eliminating visual flickering and loss of focus.

0.2 Advanced Grouping & Multi-Level Sorting

  • Multi-Level Grouping (Up to 3 Criteria): You can now group your BOM by up to three properties simultaneously in a cascading hierarchy. For example, you can group sheet metal components first by Type (Plate, Roll, Fold) and then by Thickness. This prevents dissimilar parts from merging and aligns the BOM representation with real-world manufacturing and workshop scheduling.
  • Composite Sorting with Priority Indicators: Click a column header to set the primary sort. Hold Shift and click additional headers to define secondary and tertiary sorting hierarchies (for example, Material → Part Number → Mass). Sorted columns display clear priority labels (for example, 1▲, 2▼) directly in the header.
  • Smart Grouping Protection: When a multi-level grouping is active, the quick grouping dropdown automatically locks and displays a clear Custom label. Hovering over it turns the cursor into a hand pointer, indicating that a click will open the advanced grouping configuration panel.

0.3 Data Protection & Configuration Locks

  • User-Protected Columns: You can now mark specific columns as Protected within the Configuration Editor. This is designed to safeguard fields and properties that are automatically populated by company iLogic rules, databases, or external triggers, preventing manual overrides by users.
  • Visual Lock Indicators: Protected columns are automatically styled with a light grey background, and a secure lock icon (🔒) is displayed in the column header, giving clear visual feedback on read-only columns.
  • Physical Write Protection Respect: The Viewer natively honors Inventor's built-in write restrictions. It automatically detects and locks rows corresponding to iPart and iAssembly members, Content Center components, and read-only files on disk, displaying the specific restriction reason in the status bar or as a tooltip.

0.4 Clipboard, Formulas & Casing Batch Actions

  • Direct Inventor Formula Editing: Double-clicking an editable cell that contains an Inventor formula (such as =<Description> or =<PartNumber>) loads the actual underlying formula into the text box instead of the evaluated static text, allowing you to edit or correct formulas directly from the grid.
  • Group-Level Text Transformations: When a grouped row displays <Varies> (indicating that the underlying components have different values), you can right-click the text box during editing to apply UPPERCASE or Capitalize (Title Case). The Viewer will silently propagate this formatting to all physical components of the group in the background under a single, clean transaction.
  • Restored Editing Clipboard: A dedicated right-click context menu inside the cell text box restores standard clipboard actions (Undo, Cut, Copy, Paste, Delete, Select All), with menu items dynamically enabling or disabling based on the active editing state.

0.5 Live Search & Precise Highlighting

  • Instant Live Search: The search engine updates the grid results in real-time as you type or change parameters (such as the target column or search mode). There is no need to manually click the search button to see the filtered dataset.
  • Perfect Substring Highlighting: The text highlighting system has been re-engineered using zero-margin character drawing. This eliminates artificial spaces and gaps (such as Assembly rendering as Ass embly) when displaying matched search strings, keeping the text smooth and perfectly readable.
  • Cohesive State Feedback: The search button dynamically updates its icon: it turns into an active reset filter (📥) when a search is running, and stays perfectly aligned with the semantic colored border of the grid container.

0.6 CAD/BIM Revit Category Support

  • Revit Family Category Mapping: Built-in support for the standard Revit Category property allows seamless CAD/BIM model coordination. Localized category IDs are automatically mapped to descriptive, user-friendly names in your grid, and writing back to this field correctly updates the model definition.

0.7 Per-Document Layouts & Presets

  • Assembly-Specific Layouts (AutoSave): The Viewer remembers column visibilities, custom widths, active filters, and sorting choices individually for each assembly. This is managed automatically via file-specific secure hashing, so you never lose your layout configuration when switching between different projects.
  • Structured Presets Menu: The presets dropdown has been organized into clear, intuitive sections separating system default templates, user-saved presets, and administrative template actions.
  • Redefine Default Template: Administrators can save the current grid layout as the new default starting template for the entire company.
  • Factory Reset: A clean reset option allows you to restore the default factory layout at any time, resetting column arrangements and clearing filters while fully preserving your custom, user-defined properties.

0.8 General Fixes & Stability Enhancements

In addition to the main features, several minor issues have been resolved to improve overall reliability and performance:

  • Resolved Search Overlap: Fixed an issue where searching under (All Columns) would incorrectly match hidden columns (such as File Path acting as the background key for the Thumbnail column). The search engine now strictly limits its scan to visible text columns.
  • BOM Quantity Accumulation Fix: Resolved a discrepancy where quantities were not correctly summed when grouping by certain physical metadata.
  • Zombie Reference Auto-Healing: Implemented a silent self-healing mechanism that automatically clears and rebuilds the memory cache if physical components are modified or deleted outside the active form session, preventing potential application crashes.
  • Double-Buffering UI: Applied double-buffering across all grid panels, eliminating flickering and rendering anomalies when scrolling through large bills of materials.

1. Introduction

Welcome to the GLR Advanced BOM Viewer, a powerful add-in for Autodesk Inventor designed to revolutionize how you interact with your Bill of Materials (BOM). This tool goes beyond Inventor's standard capabilities, offering a flexible and highly configurable interface to view, analyze, group, validate, and export your assembly data quickly and efficiently.

1.1 Key Features

  • Powerful Data Grid: View your data in a modern grid featuring sorting, advanced column filters, and multi-value global search.
  • Total Configuration: You decide which properties to display (iProperties, physical properties, custom properties) and in what order.
  • Multiple Views:
    • Structured: Analyze your BOM while maintaining the sub-assembly hierarchy.
    • Parts Only: Get a complete, flat list of every individual part.
    • From Selection: Instantly inspect only the components you have selected in the Inventor model.
  • Dynamic Grouping: Group identical rows based on any property (e.g., Part Number, Material) to get aggregated totals. Features a hierarchical fallback logic (Property → Part Number → File Name) to ensure components are always logically aggregated even when metadata is partially missing.
  • Interactive Dashboard: Visualize your BOM data with dynamic pie or bar charts. Click on chart segments to instantly select corresponding components in the data grid and the 3D model. Numerical values are mathematically normalized to ensure proportional accuracy regardless of the displayed unit.
  • Validation Checker: Define custom rules to automatically highlight invalid or missing data (e.g., "Material is required", "Part Number must be in uppercase"). Non‑compliant cells are highlighted in orange with a descriptive tooltip.
  • In‑Place Editing: Edit many iProperties, Material, Appearance, and BOM Structure directly from the grid, with support for dropdown lists (Value Lists) and dedicated pickers.
  • Custom Presets & Auto‑Save: Save and load your favorite view configurations. The tool features an "Auto-Healing" logic: when a preset is loaded, it automatically re-enables any required properties in the global configuration across all views.
  • Advanced Export: Export your current view to professionally formatted Excel (.xlsx), web-ready HTML, or data-interchange CSV format, including component thumbnails and validation comments.
  • 3D Model Interaction: Selection is synchronized in real-time between the grid and the Inventor 3D model. Partial selections are shown with a grey border, full selections with a blue border.
  • Model States Support: Each Model State is treated as a distinct document, ensuring correct mass, properties, and thumbnails. When a member is edited, the factory document is automatically unlocked.
  • Unit Conversion & Integrity: Length and mass values can be displayed in strict (document) units or converted. In Strict Mode, discordant units within a group are flagged with <Error> to prevent mathematical inconsistencies.
  • BOM Override Recognition: Quantities overridden in Inventor (blue text) are displayed in italic underlined style. BOM Structure overrides are shown with a tooltip indicating the Native Value.

2. Installation and Uninstallation

2.1 Installation

  1. Ensure Autodesk Inventor is closed.
  2. Run the provided setup file (GLR_Advanced_BOM_Viewer.msi).
  3. Follow the simple on-screen instructions. The installation does not require administrator privileges.
  4. First-Time Run Security Alert: The first time you start Autodesk Inventor after installation, you may see an "Add-in Manager Security Alert" because the add-in is not digitally signed by Autodesk. This is normal. Click "Launch Add-in Manager".
  5. Enable the Add-in: In the Add-In Manager window:
    • Find "Advanced BOM Viewer" in the list.
    • Ensure the "Loaded/Unloaded" and "Load Automatically" check boxes are ticked.
    • Click OK.
  6. The add-in is now ready. You will find its launch button in the "Assemble" tab of the ribbon, inside the "GLR Tools" panel.

2.2 Uninstallation

To uninstall this plug-in, first exit Autodesk Inventor. Then, you can either:

  • Re-run the installer (.msi file) and select the "Uninstall" option.
  • OR, go to the Windows Control Panel → Programs and Features (or Apps & Features), find "GLR Advanced BOM Viewer" in the list, and choose "Uninstall".

2.3 Temporarily Disabling the Add-in

You can unload the plug-in without uninstalling it by opening the Add-In Manager in Inventor (Tools tab → Add-Ins) and unchecking the "Loaded/Unloaded" box for the "Advanced BOM Viewer". You may need to restart Inventor for the change to take full effect.

3. User Interface Guide

The main window is divided into several areas: the Top Bar, the Data Grid, the Dashboard, and the Status Bar.

3.1 The Top Bar: Your Control Panel

  1. Main Actions:
    • Export ▾ – Opens the Export Options window to generate a report. You can choose between Excel (.xlsx), HTML, and CSV formats. For Excel and HTML exports, the file will include a complete header with the report context, your Inventor User Name, and any optional notes you add. Thumbnails are embedded in Excel and HTML.
    • Dashboard – Toggles the visibility of the interactive Dashboard panel at the bottom of the window. Use this to perform visual analysis of your BOM data.
    • Checker – Enables or disables the validation system. When enabled, cells that violate defined rules are highlighted in orange. You can also filter the grid to show only non‑compliant rows.
    • Presets ▾ – Manages your saved views. Save the current setup or load a previously saved one. Loads search, grouping, and filters for all views simultaneously to ensure a consistent session environment.
    • Update Mass – Forces a recalculation of physical properties (Mass, Area, Volume) for all documents currently visible in the grid. The button is enabled only when there are visible documents whose physical properties are not yet cached or are out of date.
    • [?] (Help) – Opens this user guide.
  2. View Mode:
    • Structured: Displays the BOM, keeping sub‑assemblies as single rows. Shows the primary assembly row at the top if Show Primary is checked.
    • Parts Only: Displays a flat list of all individual parts.
    • From Selection: An "Inspector" mode. The grid only shows components currently selected in Inventor. Selection highlighting is done without modifying the Inventor selection set.
  3. Show Primary: When checked (only available in Structured view), displays the top‑level assembly as the first row, with a dark background and bold text. When the Checker is active, this row is also subject to validation rules.
  4. Group By: Select a property (e.g., Part Number, Material) to group all rows that share the same value. Fallback logic: if the chosen property is empty, the system automatically groups by Part Number, and if that is also empty, by File Name. The 📥 icon indicates that grouping is active; click the ✖ button to reset grouping to Part Number.
  5. Advanced Search Bar: Allows powerful and specific filtering of the grid. It consists of three parts:
    • Property Selector: Choose which column to search within, or select (All Columns) for a global search.
    • Condition Selector: Defines the search type (Contains, StartsWith, Exact).
    • Search Text Field: Enter your search term. Press Enter or click the magnifying glass icon (🔍) to apply.
      • Multi‑Value Search: Search for multiple values at once by separating them with a semicolon (;). For example, bolt;nut finds all rows containing either "bolt" OR "nut".
      • Blank Values: Use the token <BLANK> to search for empty cells.
  6. Show only issues (⚠️): When the Checker is enabled, this checkbox filters the grid to show only rows that contain at least one validation error. The status bar indicates the number of issues found.
  7. Reset All: Instantly clears all applied filters, resets grouping to Part Number, and clears the "Show only issues" filter.
  8. Edit Config: Opens the Column Configuration Editor (see Section 5).

3.2 The Data Grid: Your Workspace

  • Visual Feedback on Filters: When any filter (search, column filter, grouping, or "Show only issues") is active, the border of the grid panel turns red. If the "Show only issues" filter is active, the border turns orange, providing an at‑a‑glance indication that the data is filtered.
  • Sorting: Click any column header to sort the data in ascending or descending order. A small triangle (▲/▼) will indicate the sorted column and direction. Sorting uses a natural alphanumeric algorithm (e.g., Part2 comes before Part10).
  • Column Filters (∇ / 📥): Click the funnel icon (∇) in a column header to open a filter menu. Select the desired values from the list and click "Apply". The icon will change to a filled funnel (📥) to indicate that a filter is active on that column. Filters support multi‑selection and the <BLANK> token.
  • Inline Editing: Many cells are editable directly in the grid. Editable properties include:
    • Design Tracking, Summary Information, Document Summary Information, and User Defined iProperties.
    • Material (for part documents and virtual components).
    • Appearance (for part documents; also provides a Clear Override option to reset to the material‑based appearance).
    • BOM Structure (Normal, Phantom, Purchased, Reference, Inseparable).
    • When a group of rows (<Varies>) is edited, you will be prompted to confirm overwriting all files in the group.
  • Value Lists (Dropdowns): If a property has been associated with a Value List (see Section 5.3), a ▼ button appears when editing that cell. Click it to select a value from a filterable dropdown. This works for both standard iProperties and custom user‑defined properties.
  • Recognition of BOM Overrides:
    • Quantity Overrides: Quantities that have been manually overridden in Inventor (displayed in blue in the standard BOM) are shown in the italic underlined style in the grid. This makes overridden values instantly recognisable.
    • BOM Structure Overrides: When a component's BOM Structure is changed (e.g., from Normal to Reference), the cell displays the new value in italic and, when hovered, shows a tooltip indicating the Native Value (e.g., Default: Normal).
  • Unit Integrity <Error>: In Strict Mode, if a group contains discordant units (e.g., a mix of mm and inches, or kg and lb), the total columns will display <Error>. This is a safety feature to prevent incorrect mathematical sums. To resolve this, simply enable a conversion mode in Tab 7 to normalize all values.
  • Validation Highlighting: When the Checker is enabled:
    • Cells that fail validation rules are shown with an orange background and bold black text.
    • Hovering over an invalid cell displays a tooltip with the error message (e.g., "Part Number is required").
    • Rows that contain any invalid cell are considered non‑compliant. You can filter to show only these rows using the ⚠️ Show only issues checkbox.
  • Context Menus (Right-Click): The right-click menus provide powerful contextual commands.
    • Right-Click on a Column Header:
      • Remove Column: Temporarily hides the selected column from the current view. This change can be made permanent by saving the view as a Preset.
      • Add Column...: Opens a dialog to select a property from the global pool and add it as a new column to the current view. The column is inserted after the clicked column.
      • Edit Column Configuration...: Provides a convenient shortcut to open the full Configuration Editor.
    • Right-Click on a Grid Row: The available commands change depending on whether you have rows selected.
      • With one or more rows selected:
        • Open Selected: Opens the component file in Inventor (available for single‑row selection only; disabled for groups or virtual components).
        • Show Selected: Makes the corresponding components visible in the model.
        • Hide Selected: Hides the corresponding components in the model.
        • Isolate Selected: Hides all other components, leaving only the selected ones visible.
        • Clear Selection: Deselects all rows in the grid and all components in the model.
      • With NO rows selected:
        • Undo Isolate: Reverses the last Isolate command performed in the assembly.
        • Show All: Makes all components in the assembly visible.
        • Hide All: Hides all components in the assembly.
  • Selection Synchronization:
    • Selecting rows in the grid automatically selects the corresponding occurrences in Inventor.
    • Selecting components in Inventor highlights the corresponding rows in the grid.
    • When a row contains multiple occurrences but only a subset is selected in Inventor, the row border becomes grey (partial selection). When all occurrences are selected, the border is blue (full selection).
    • In From Selection mode, the grid does not modify the Inventor selection set; instead, it uses a green highlight set to visually indicate the selected components.
  • Handling of Unsaved Documents: If you have never saved a document (indicated by [Unsaved] in the grid), the tool still works correctly. When you later save the document, all related data (properties, mass, thumbnail) are automatically migrated to the new file identity – no information is lost.

3.3 The Status Bar: Real-Time Information

The bar at the bottom of the window provides contextual status messages, such as the number of rows displayed, any warnings, and the current filter summary. When the Checker is active, it also shows the number of detected issues.

3.4 The Dashboard: Visual Analysis

The Dashboard provides an interactive graphical representation of your Bill of Materials data. It is directly linked to the data visible in the grid, respecting all active filters and groupings.

  1. Activating the Dashboard: Click the Dashboard button in the top bar. A new panel will appear below the data grid. The splitter position is remembered between sessions.
  2. Analyze Property: Use this dropdown to select the property you want to visualize. The list is organized to show categorical properties (like Material) first, followed by numerical properties (like Total Mass).
  3. Mathematical Truth: For numerical properties, values are automatically normalized to a consistent unit (e.g., all masses in kg, all lengths in cm) before being displayed. A 1 kg part will always look twice as large as a 0.5 kg part, regardless of whether the grid displays kg, lb, or grams.
  4. Interactive Selection: Click on a slice of the pie chart to:
    • Instantly select all corresponding rows in the data grid.
    • Instantly select all corresponding components in the Inventor 3D model.
    This allows you to quickly identify and locate components based on their properties (e.g., "select all Steel parts", "find the heaviest components").
  5. If the number of categories exceeds the limit (8 for pie), the chart automatically aggregates the smallest categories into an "Others" slice.

4. Typical Workflows (Use Cases)

"I want a report of all screws and bolts."
  1. Select the Parts Only view.
  2. In the search bar, type screw;bolt and press Enter.
  3. Click Export... and choose Excel.
"I want to find all 'Purchased' components missing the 'Vendor' property."
  1. Select the Structured view.
  2. Filter the BOM Structure column to show only "Purchased".
  3. Define a Validation Rule on the Vendor property with a condition: BOM Structure Equals "Purchased" → Check: Required.
  4. Analyze by Vendor in the Dashboard: the <BLANK> slice represents missing data. Click it to isolate them.
"I want to identify the heaviest components, regardless of their document units."
  1. Click the Dashboard button to open the analysis panel.
  2. From the Analyze Property dropdown, select Total Mass.
  3. The chart will immediately show the distribution. Thanks to internal normalization, components using 'lb' and 'kg' are compared correctly.
  4. Click on the largest slice to select and highlight the heaviest component(s) in both the grid and the 3D model.
"I want to verify that all sheet metal parts have a material assigned."
  1. Open Edit Config and ensure the SubType and Material properties are visible and enabled.
  2. Select the Parts Only view and filter the SubType column to show only "Sheet Metal".
  3. Open the Dashboard and analyze by Material. You will instantly see a slice for <BLANK> if any parts are missing a material. Click it to select them all.
  4. Alternatively, enable the Checker and define a rule that makes Material required. Non‑compliant rows will be highlighted in orange.
"I want to know the total length or mass of each profile used in my frame."
  1. Select the Parts Only view.
  2. Enable the Stock Number column in the configuration.
  3. Apply grouping by Stock Number to merge identical profiles. Aggregated totals will be shown even for profiles across different sub-assemblies.
"I need a documented report for a supplier, including my notes."
  1. Prepare the data using filters and grouping.
  2. Click Export... and in the Notes & Comments field, add your remarks (e.g., "BOM for quotation QF-1234").
  3. Choose Excel (.xlsx) or HTML format. The exported file will include a header with your notes, the view context, active filters, and your User Name for full traceability. If the Checker is active, validation comments are embedded as cell comments in Excel.
"I want to ensure all Part Numbers follow a standard format and are Uppercase."
  1. Open Edit Config and go to the Validation Rules tab.
  2. Select the Part Number property.
  3. Add a Check of type Pattern (Regex: ^[A-Z]{3}-\d{5}$) and a Check of type Upper Case.
  4. Save and enable the Checker. Cells that do not match the format or casing will turn orange.

5. Advanced Configuration (Edit Config)

The Configuration Editor gives you complete control over the information displayed, validation rules, value lists, and unit preferences.

5.1 Tab 1: Property Management

This is the main tab where you define the "pool" of all properties available to the add-in.

  • Main Grid:
    • Enabled: A property must be checked here to be available in any view. Disabling a property that is used in validation rules will automatically disable those rules.
    • Label: The name that will appear in the column header.
    • Data Source: Defines the origin of the property (Design Tracking, Summary Info, Document Summary Info, User Defined, etc.).
    • Property: For standard properties, choose from a list; for custom User Defined properties, type the exact iProperty name.
    • Use in...: Check the boxes to determine in which views the property will be visible by default.
    • Analytics: Check this box to make the property available for analysis in the Dashboard. Only properties that are meaningful to visualize (like Material, Mass, Quantity) should be enabled.
  • Special System Properties: Some properties like FileName, PartNumber, and Thumbnail are protected and cannot be disabled. The Model State property, when enabled, displays the current Model State name (e.g., [Primary], coarse) – it is read‑only and protected.

5.2 View Ordering Tabs (2, 3, 4)

Each of these tabs ('Structured' View, 'Parts Only' View, etc.) controls the column order for its corresponding view. Use the ↑ Up and ↓ Down buttons to move a selected property.

Tip: After configuring your views, save them as a Preset for easy recall in the future!

5.3 Tab 5: Value Lists

Value Lists allow you to define predefined dropdown values for any property. They are used both in the grid editing (dropdown button) and in validation rules (e.g., "In List" condition).

  • Create a List: Click New List, give it a name, then use Add to insert values (multiple values can be added at once by separating them with semicolons).
  • Modify a List: Select a list from the left panel. You can rename, delete, add, edit, delete, or reorder values using the buttons provided.
  • Associate a List with a Property: In the bottom table "Property Associations Mapping", each property shows a dropdown where you can assign a Value List. Once assigned, editing that property in the main grid will show a dropdown with the list's values. The association is saved in the global configuration.
  • If a list is deleted or renamed, all references in validation rules and property associations are updated automatically.

5.4 Tab 6: Validation Rules

Validation rules allow you to define automatic checks on the data entered in the cells. When the Checker is enabled (main toolbar button), cells that violate a rule are highlighted in orange and show an error message on mouse hover.

A rule consists of two main parts:

  • Conditions (optional): determine when the rule should be applied. If no conditions are specified, the rule always applies to the target property.
  • Checks (mandatory): define what makes the value non‑compliant. Each rule must have at least one check.

5.4.1 Conditions – "When to apply the rule"

Conditions allow you to restrict validation to specific contexts. For example, you may want to check that a material is present only for "Sheet Metal" components.

Each condition compares the value of another property (not the target) using an operator. Multiple conditions can be combined using the logical operators AND (all must be true) or OR (at least one true).

Operators available for conditions:

  • Equals / Not Equals – case‑insensitive equality.
  • Is Empty / Is Not Empty – checks whether the property is empty.
  • Contains / Not Contains – checks for the presence of a substring.
  • Starts With / Ends With – checks prefix/suffix.
  • In List – checks if the value belongs to a Value List (see Section 5.3).

5.4.2 Checks – "What makes the value invalid"

Checks are the actual validations on the target property's value. A rule can have multiple checks: all of them must pass for the cell to be considered valid.

Available check types:

  • Required – the value cannot be empty or whitespace only.
  • Min Length / Max Length – enforces a minimum/maximum number of characters.
  • In List / Not In List – the value must (or must not) belong to a predefined Value List.
  • Pattern – checks that the value matches a regular expression (Regex). The ... button opens the Pattern Builder to create the regex visually.
  • Upper Case / Lower Case – forces the value to be entirely uppercase or lowercase.

Each check can have a custom error message. If left empty, the system automatically generates a descriptive message (e.g., "Part Number is required.").

5.4.3 Practical examples

Example 1 – Standardized Naming (Pattern + Case)
Goal: "Descriptions must start with 'FRAME-', be all uppercase, and follow a numeric pattern XXXX."
  • Check 1: Starts With: "FRAME-"
  • Check 2: Upper Case
  • Check 3: Pattern (Regex): ^FRAME-\d{4}$
Example 2 – Conditional Procurement Data
Goal: "If a part is 'Purchased', it MUST have a 'Vendor' and 'Stock Number'."
  • Rule A (Vendor): Condition: BOM Structure Equals "Purchased" → Check: Required.
  • Rule B (Stock Number): Condition: BOM Structure Equals "Purchased" → Check: Required.

5.4.4 Managing rules in the editor

  • Status icons:
    • ✅ – Rule active and valid (all property and Value List references exist).
    • ⚠️ – Rule active but has no checks (cannot be saved).
    • 🔴 – Broken rule (target property or condition properties disabled, missing Value List).
    • ○ – Rule manually disabled.
  • Enabling/disabling a rule: Use the Enabled checkbox in the rule editor. Disabled rules are not evaluated.
  • Automatic dependencies: If a property used in a rule is disabled in Tab 1, the rule is automatically disabled and shown as broken. When the property is re‑enabled, the system asks whether to also re‑enable the rule.

5.5 Tab 7: Unit Settings

Control how physical quantities (Length and Mass) are displayed in the grid. These settings are global and remembered between sessions.

  • Length Mode:
    • Strict – displays values in the original unit of each document (e.g., mm, cm, in).
    • ToDocumentUnit – converts all length values to the unit of the top‑level assembly document (e.g., if the assembly is in mm, all lengths are shown in mm).
    • ToCustomUnit – converts all length values to a user‑defined unit (select from mm, cm, m, in, ft).
  • Mass Mode: Same logic as Length, with units kg, g, slug, lb.
  • Decimal Places: Choose the number of decimal places (0 to 8) for each category. The preview shows the formatting (e.g., "3,123" for 3 decimals).
  • Unit conversion applies to columns such as Base Quantity, Total Quantity, Item Mass, Total Mass, Item Area, Item Volume, etc. The Dashboard also uses normalized units for consistent chart proportions.
