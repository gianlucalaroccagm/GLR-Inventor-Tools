1. Key Features

GLR Advanced BOM Viewer is a window on your assembly's Bill of Materials that stays open while you work in the model. It reads the components of the active assembly with the same quantity rules as Inventor, and lets you do what the Inventor BOM cannot: filter, group, check, edit in bulk, compare and report.

  • Always open, always in sync – Work in the model with the BOM beside it: selection goes both ways, and changes, model states and saves are followed live. Inventor: the Bill of Materials is a dialog you must close to work in the model.
  • Three views and a real tree – Model Data, Structured and Parts Only, each with its own columns and filters; open sub-assemblies branch by branch, with the main assembly as the first row. Inventor: no row for the main assembly; Structured and Parts Only must be enabled first.
  • Find anything in seconds – Search with operators for text, numbers, dates and yes/no, several values at once, Excel-style column filters, and Isolate rows to keep just what you selected. Inventor: no filters in the BOM editor.
  • Group by anything – Group rows by any property, up to three levels (Material > Thickness > Part Number); <Varies> shows where the files of a row disagree. Inventor: grouping only in the drawing parts list.
  • Edit hundreds of rows at once – Paste a column from Excel, give one value to many rows, fix letter case, change material, appearance or BOM Structure on many components: one Undo step per command. Inventor: one cell at a time.
  • Safe editing – Library, Content Center and read-only files, iPart/iAssembly members and protected columns are locked with the reason; formulas are shown and protected; value lists guide the input. Inventor: no value lists, no protected columns.
  • Validation rules – Your company rules (required fields, allowed values, formats, letter case) are checked on every component; Show only issues turns the problems into a work list, also in the 3D model. Inventor: no data checks without iLogic programming.
  • BOM Compare – Compare with another model state, iAssembly member or assembly file: added, removed and changed rows, value by value, without changing your files. Inventor: no BOM comparison.
  • See your BOM in 3D – A pie chart and colors projected on the model by any property or by validation result; click a slice to select its components. Your files are never changed. Inventor: no charts; coloring means changing appearances.
  • Reports ready to send – Excel, HTML and CSV at once, with the look of the grid, thumbnails, notes, item numbering and filters inside the file. Inventor: plain data export of one view.
  • Quantities, masses and units you can trust – Inventor's quantity rules and overrides, masses for every row, units of your choice and quick sums; a clear <Error> instead of a wrong total. Inventor: masses one file at a time, in the document units.
  • Your layouts, one click away – Presets of all three views, a personal Home layout and the memory of how you left each assembly. Inventor: column setup assembly by assembly.
  • Also for reviewers – Read-Only mode for those who only check, and full support for Inventor Read-only Mode: everything works except writing to files.
  • Your settings are safe – Every change to your settings keeps a dated backup; updates keep your settings, and factory settings are one command away.

2. Getting started

2.1 Installation

  1. Close Autodesk Inventor.
  2. Run the setup file and follow the instructions. Administrator rights are not required.
  3. The first time Inventor starts, it may show an Add-in Manager Security Alert because the add-in is not signed by Autodesk. Click Launch Add-in Manager, select Advanced BOM Viewer, tick Loaded/Unloaded and Load Automatically, then click OK.

To uninstall, close Inventor and remove GLR Advanced BOM Viewer from Windows Apps & Features. To disable it temporarily, untick Loaded/Unloaded in the Add-In Manager (Tools tab → Add-Ins).

2.2 Opening the viewer

  • With an assembly open, click the BOM Viewer button in the Assemble tab, GLR Tools panel.
  • There is one viewer window. Clicking the button again brings it to the front.
  • The window closes by itself when you switch to another document or close the assembly; open it again for the new assembly.
  • If the active model state takes its BOM from another model state, BOM Viewer asks whether to activate that one.

2.3 The window

  • Command bar: Export..., Dashboard, Checker, Multi-level, Presets, Update Mass, ↻ (refresh), Compare, 3D Heatmap, ? (this guide).
  • View row: the three views, Show Primary, Group by and Edit Config.
  • Search row: search, Show only issues, Isolate rows, Clear Filters.
  • Grid in the middle, optional Dashboard below it, and the status bar with the sums at the bottom.

2.4 Read-Only and Editor modes

  • In the Configuration Editor (tab 8, Editing Mode) choose Editor to edit, or Read-Only if you only need to review the BOM.
  • In Read-Only mode only the commands that write to your files are off. Search, filters, grouping, presets, visibility commands, BOM Compare, validation and export all keep working.
  • BOM Viewer also runs in Inventor Read-only Mode: editing is always off there.

2.5 Keeping the view up to date

  • Changes made with BOM Viewer appear at once. Changes made in Inventor (iProperties, components added or suppressed, model states), and Inventor's Undo and Redo, are picked up automatically.
  • When the data must be read again, the status bar says View out of date and ↻ turns green: click it.
  • In tab 8 of the Configuration Editor you can set Synchronization to Manual if you prefer to refresh yourself.

3. The three views

  • Model Data – the assembly as in the model browser, like Inventor's Model Data: Phantom and Reference components are real rows with their children. One row per file under each parent.
  • Structured – the BOM by levels. Phantom components are dissolved and their children move up; Reference components are left out. Tick Multi-level to open sub-assemblies as a tree.
  • Parts Only – every part in a flat list. Purchased and Inseparable assemblies count as one row.

Each view remembers its own columns, widths, filters, search, grouping, sorting and open branches. Switching view is immediate, and the components selected in the model stay selected.

Show Primary

Available in Structured: shows the main assembly as the first row, with its iProperties. You can edit them and the rules check them.

Tree views (Structured Multi-level and Model Data)

  • Click the + / - box to open or close a branch. Shift+click a closed branch to open all the levels below it.
  • Right-click the box for Expand All Children and Collapse Sub-assembly.
  • A branch shows the BOM of one occurrence of the sub-assembly, as in Inventor.
  • In tree views grouping is fixed (rows follow Inventor's structure), column filters and the Dashboard are not available, and the sums add up only the selected rows.
Beyond Inventor
  • The views are built from the model: Structured and Parts Only work even if they are not enabled in the assembly BOM.
  • The tree opens branch by branch and remembers the open branches of each view.

4. The grid

4.1 Columns

  • Right-click a column header for Remove Column, Add Column..., filters, sorting and Edit Column Configuration...
  • Add Column... lists the properties not yet shown, with a search box and multiple selection. New columns are inserted where you clicked. The + button creates a new custom iProperty on the spot.
  • Drag a header to move a column; drag its border to resize it. Double-click the border of the first column in tree views to fit indents and icons.
  • Header icons: 🔒 protected column, ☰ column with a value list, ▲▼ sorting, funnel for filters. An italic light-blue header means the values are converted to another unit.

4.2 Icons and thumbnails

  • The first column shows the type of component: part, sheet metal, assembly, weldment, Cable & Harness, tube & pipe, frame, virtual component, group of different files.
  • The Component Type column gives the same type as text, in English whatever the language of Inventor, so you can sort, filter, group and export it.
  • A blue arrow ⬆ marks a promoted component (moved up from a Phantom); the tooltip names its parent. A grey frame marks files referenced from the cloud.
  • The Thumbnail column shows the image of each file. Thumbnails appear all together and are reused when you reopen the window, until the file changes.
  • BOM Structure uses Inventor's own icons, in the cell and in its list.
  • Virtual parts inside a Cable & Harness assembly have their own icons (wire, cable, ribbon, splice, terminal...).

4.3 Sorting

  • Click a header to sort; click again to reverse. Shift+click more headers to sort by several columns (1▲, 2▼...).
  • Sorting is natural (Part2 before Part10). In tree views each level is sorted inside its parent; the main assembly stays on top.

4.4 Selection with the model

  • Select rows to select their components in the model; select in the model or browser to select the rows. In tree views the branches open to show them.
  • A grey row border means only some occurrences of the row are selected in the model; a blue border means all of them. Click the row to select them all.
  • If a selected component is not shown by the view (for example hidden by a filter), the status bar says N excluded from BOM view.
  • Arrow keys keep the current column; Shift or Ctrl + arrows extend the selection.

4.5 Row menu (right-click)

  • Copy, Paste, Edit properties..., Uppercase, Title Case – see Editing.
  • Open Selected – opens the file of one row.
  • Isolate Selected, Show Selected, Hide Selected, Undo Isolate, Show All, Hide All, Clear Selection. The command names show how many occurrences they affect.
  • iProperties... – Inventor's iProperties of the selected components, or of the main assembly from its row.
Beyond Inventor
  • Isolate Selected also shows selected components that were hidden, then isolates them, in a single Undo step. Inventor isolates only the visible ones.
  • If you selected only some occurrences of a row in the model, the visibility commands act on just those (1 of 4 occurrences).

4.6 Status bar and sums

  • The status bar shows the number of rows, the selection (N rows selected (M occurrences in model)), the active cell value, its formula and, for a locked cell, the reason.
  • The active preset is shown as Layout: name (see Presets).
  • Sum Items, Sum Qty and Sum Mass work like the Excel status bar: they add up the selected rows, or all rows shown when nothing is selected (only selected rows in tree views). The main assembly row is not counted.
  • <Error> means the values cannot be added correctly (pieces mixed with lengths, or different units); N/A means some masses are missing: click Sum Mass to calculate them.
  • Cell tooltips explain what you see: why a cell does not comply, the values behind <Varies>, unit conflicts, overrides.

5. Search and filters

5.1 Search

  • Choose a column (or (All Columns), the columns shown) and an operator, type the value and press Enter. While the search is active the grid follows every change you make.
  • The operators depend on the column: Contains, Starts With, Ends With, Exact Match, Is Empty for text; =, >, <, >=, <= for numbers; On Date, Before, After for dates; Is True, Is False for yes/no.
  • In text columns, separate several values with ; (bolt;nut) and use <BLANK> for empty cells. The text found is highlighted.
  • Type dates in your Windows date format (shown in the empty box), or pick them with the calendar button next to the box.
  • The red funnel button means a search is active: click it to remove it.
  • In tree views the search keeps the rows found plus their parents, so you always see where a component sits; the branches open by themselves. Use ◀ ▶ to jump between results: N of M.

5.2 Column filters

  • Click the funnel in a header to filter like in Excel: tick the values to keep, <BLANK> for empty cells, then Apply.
  • Filters on different columns work together; the list of each filter shows only the values left by the other filters (Values limited by: ...).
  • Column filters are available in Structured (single level) and Parts Only.

5.3 Isolate rows

Select some components (in the grid or in the model) and tick Isolate rows: only their rows stay, and the list does not change while you click other rows. Untick it to see everything again. The status bar shows Isolated: N occurrences.

5.4 Clear Filters and the grid frame

  • Clear Filters removes search, column filters, Show only issues, Isolate rows and custom grouping in one click; its tooltip lists what it will clear.
  • A colored frame around the grid tells you that something is filtered: red for filters and search, orange for Show only issues, blue for Isolate rows alone.
Beyond Inventor
  • Inventor's BOM editor has no filters; here you search and filter any column, also in the tree, while the model stays usable.

6. Grouping

  • Group by joins the rows that share a value. Part Number is the default; File Name is always available, plus any visible column that can be grouped.
  • The Group Settings button next to it lets you group by up to three properties in cascade, for example Material > Thickness > Part Number.
  • When the components of a row have different values, the cell shows <Varies> and the tooltip lists every value, empty ones included. Values that differ only in letter case count as the same value.
  • Grouping never mixes different articles: a Part Number whose files disagree on a grouping property stays on its own row.
  • A group row containing a protected file is locked as a whole.
  • In tree views grouping is fixed: by Part Number in Structured Multi-level, one row per file under each parent in Model Data.
Beyond Inventor
  • Inventor groups only in the drawing parts list. Here you group by any property, in cascade, right in the viewer.

7. Editing

Editing requires the Editor mode (see 2.4). Every command is one step in Inventor's Undo list, named BOM Viewer: Edit 'Description', BOM Viewer: Paste 'Description' and so on; nothing is added when nothing changes.

7.1 In the cell

  • Double-click, press F2 or start typing; press Enter to write.
  • Columns with a value list, Material, Appearance, BOM Structure, Revit Category and yes/no show a drop-down; date columns open a calendar with Clear. Number columns accept only numbers.
  • A group row is one row: the value is written to every file in it.
  • To change several rows, use Paste or Edit properties: with several rows selected the cell does not open for editing.

7.2 Copy and Paste

  • Ctrl+C copies the cell, or the values of the column for all selected rows, one per line. A formula is copied as a formula.
  • Ctrl+V pastes one value into all selected rows, or a list of values (for example a column copied from Excel) into as many selected rows, in order.
  • Paste writes where it can: for each locked row it asks whether to skip it and continue (Apply to all remaining cases answers for all of them).

7.3 Delete, Edit properties, Uppercase, Title Case and Replace

  • Delete empties the cell. Material, Appearance, BOM Structure and Revit Category cannot be emptied.
  • Edit properties... (right-click) gives one value to all selected rows, with the right input: list, calendar or text box. It is off if any selected cell is locked, and when the main assembly row is selected together with other rows (Paste can write both).
  • Uppercase and Title Case convert the text of the selected rows in text columns.
  • Replace... replaces a text inside the values of the selected rows (Find, Replace with, Match case). Formulas are not changed. If the text is not found, a message says so.

7.4 Formulas

  • A value starting with =, such as =<Part Number>-<Revision>, is written as an Inventor formula in text columns.
  • While editing you see the formula, in the grid its result. Before a formula is replaced you are asked.

7.5 Locked cells and values

  • Locked cells are grey; click one and the status bar tells you why: Read-Only mode, read-only or library file, Content Center, iPart/iAssembly member, protected column, data to refresh.
  • A value outside the column's value list is written only after you confirm it. Numbers, dates and yes/no values are checked before writing.
  • Validation rules never stop you: the value is written and the cell shows whether it complies.
  • If some files cannot be written, the others are written and a message lists what was skipped.
  • No editing during BOM Compare.
Beyond Inventor
  • Edit many rows at once, paste a column from Excel, fix letter case in one click, while the model stays open.
  • Library and Content Center files, members and protected columns cannot be overwritten by mistake.
  • Formulas are visible and protected.

8. Material, Appearance, BOM Structure, Revit Category

  • These columns accept only valid values: pick them from the list. A value typed or pasted with a different spelling is corrected for you; an invalid one is never written.
  • Material and Appearance list the active Inventor library plus the assets already in the file, like Inventor. Change the material of many parts at once with Paste or Edit properties: masses update immediately.
  • When you change the material, the appearance follows it, unless you had chosen an appearance yourself: that one is kept.
  • Choose (Clear Appearance Override), the first item of the Appearance list, to bring parts back to the appearance of their material.
  • Weldments and virtual components have a material too, in the same column. Assemblies and model state members cannot get a material from the grid.
  • BOM Structure shows Inventor's icons. Phantom and Reference reshape the BOM and the grid follows at once. For model states, iParts and iAssemblies the value is written for all members.
  • Revit Category offers the Revit categories and is written for all model states of the file.
  • A BOM Structure overridden in the assembly is shown in italic underline; the tooltip shows the file's own value.
Beyond Inventor
  • Material, appearance and BOM Structure on many components at once, with a single Undo step.

9. Quantities, masses and units

  • Quantities follow Inventor's rules: Phantom children move up with the Phantom quantity, Reference components are left out, Purchased and Inseparable assemblies count as one row, and quantity overrides are read from the assembly BOM.
  • Overridden quantities are shown in italic underline, with the tooltip Quantity is overridden in Inventor Assembly BOM.
  • Columns: Item Qty, Total Qty, Base Qty, Item / Total Mass, Item / Total Area, Item / Total Volume, also for group rows. Total Mass is the real mass of the occurrences, as in Inventor.
  • A mass that Inventor has not updated shows N/A, never an old value. Update Mass calculates only the files that need it, without marking them as modified: the rows shown, and in tree views the whole assembly, closed branches included. The button lights up whenever a row on screen shows N/A.
  • In the Configuration Editor (tab 7) choose how lengths, masses, areas and volumes are shown: in each file's unit (Strict), in the main assembly's unit, or in a unit of your choice, with your number of decimals. Areas and volumes use the length unit squared or cubed (for example mm^2 and mm^3), as in the iProperties of Inventor.
  • When values cannot be added correctly (pieces with lengths, or different units in Strict), the cell shows <Error> and the tooltip explains why.
Beyond Inventor
  • Masses, areas and volumes of every row in one place, with quick sums of the selected rows.
  • Units under your control, and a clear warning instead of a wrong total.

10. Validation rules and Show only issues

  • Rules check your iProperties automatically: required fields, allowed values (value lists), length, minimum and maximum value (numbers and dates), format (patterns) and letter case. You write them once in the Configuration Editor (tab 6) and they apply to every assembly.
  • A rule applies to all components, or only to those that meet its conditions (AND / OR), for example BOM Structure equals Purchased.
  • Turn validation on or off with the Checker button. A non-compliant cell is highlighted; hover over it to read why.
  • On a group row, the tooltip tells you how many files do not comply and which ones. Rules on Item Qty, Total Qty, Total Mass, Total Area and Total Volume check the row total.
  • Only the columns shown in the grid are checked.
  • Tick Show only issues to keep only the non-compliant rows; the box shows how many there are. It is a work list: rows you fix stay until you turn the filter off and on again or refresh.
  • In tree views, Show only issues searches the whole assembly and opens the branches that contain problems; turning it off closes them again.
Beyond Inventor
  • Company rules without iLogic programming, with a list of the problems to work through and their color in the 3D model (see 3D Heatmap).

11. Dashboard and 3D Heatmap

11.1 Dashboard

  • Click Dashboard to open a pie chart below the grid. In Analyze Property choose one of the properties marked Analytics in the Configuration Editor.
  • The chart counts the rows shown: search and filters change it. The seven largest values get their own slice; the others are joined in Others.
  • Each value keeps its color: the same color appears in the chart, in a strip on the left of each row and in the 3D model.
  • Click a slice to select its rows and components; click it again to clear the selection.
  • Tick 3D Heatmap in the panel to color the model with the chart colors.
  • Right-click the chart to copy or save its image, or to show, hide or isolate the components of a slice.

11.2 3D Heatmap

  • The 3D Heatmap button colors the model by any visible column, or by Validation Issues (compliant and non-compliant parts). Clear Heatmap removes the colors.
  • The colors follow your work: they update after edits, visibility changes, open branches, model state changes and shape changes.
  • The colors are temporary graphics: your files are never changed and Inventor's Undo list stays clean.
  • Hidden, suppressed, reference and virtual components are not colored, nor are parts with more bodies than the limit set in the Configuration Editor (tab 9). Opacity is set there too.

Dashboard and 3D Heatmap are not available in Model Data and during BOM Compare; the Dashboard is also off in Structured Multi-level.

Beyond Inventor
  • Colors by property value, stable and with the same meaning in chart, grid and model, without touching the appearances of your files.

12. BOM Compare

  • Click Compare (in Structured or Parts Only) to compare the open assembly (Base) with a Target: another model state, another member of the same iAssembly, or another assembly file (<Browse external IAM...>).
  • Choose the Target and click Play (▶). The model always shows the Base, your files are never changed and Inventor's Undo list stays clean.
  • Added rows are blue, Removed rows red and struck through, changed cells of Modified rows blue and bold. Hover a changed cell to see the previous value; a value emptied in the Target is shown struck through.
  • Use the Added, Removed, Modified and Unchanged boxes to show only the rows you need. Differences in letter case only are not reported.
  • If you change the model in Inventor during the comparison, Play turns green: click it to compare again.
  • Members that have not been generated are never created by BOM Compare: generate them in Inventor first.
  • Editing, Dashboard, Checker and 3D Heatmap are off until you click Exit Compare. BOM Compare also works in Inventor Read-only Mode.
Beyond Inventor
  • Inventor has no BOM comparison. Here you see what was added, removed or changed, value by value, and you can export it.

13. Export

  • Click Export... and tick one or more formats: Excel, HTML, CSV. You get one file per format.
  • All rows (default): the file contains the complete BOM, with all branches open; searches and filters of the grid are not applied. Only rows shown in the grid exports exactly what you see.
  • The columns are the ones shown in the grid, in the same order.
  • Add your notes and optional item numbering (label, start value, increment, delimiter; 1.2.3 by level in tree views). The file header shows assembly, view, filters, date and author.
  • Excel and HTML keep the colors, thumbnails and tooltips of the grid and include filters to work on the file. The grey of cells you cannot edit is not exported: it only matters in the grid. In Excel numbers and dates are real values and tree levels are grouped with + and -. The HTML file opens in any browser and prints the whole table with the header on every page.
  • The HTML file is a picture of the grid: its first column has the same tree lines and component icons (not in BOM Compare). Excel is for working with the data and has no drawings; use the Component Type column if you need the type of each row.
  • CSV contains the data only, with a Level column in tree views.
  • With the Checker on, an Issues column tells which rows comply. During BOM Compare you can export the comparison to Excel or HTML, with a Change column.
Beyond Inventor
  • Reports ready to send, with the look of the grid, thumbnails, notes and filters, in several formats at once.

14. Presets, Home and session memory

  • A preset is a snapshot of all three views: columns, widths, filters, search, grouping and Multi-level.
  • Presets > Save Preset... suggests a name: press Enter to save. A name already in use is saved as name (1).
  • Click a preset in the Presets menu to load it in one step. The status bar shows Layout: name, and (Modified) after you change columns, filters or grouping.
  • Home is your starting layout (columns only), used for assemblies opened for the first time. Presets > Home restores it and clears filters, search and grouping.
  • In Manage Presets... you rename, update, delete and load presets and set your Home; changes are saved with Apply or Save and Close.
  • BOM Viewer remembers how you left each assembly, including the active preset. Choose how in the Configuration Editor, tab 8, Session Persistence.
  • If a preset uses a property that no longer exists, it still loads and the status bar lists what is missing.

15. Configuration Editor

Click Edit Config to set up BOM Viewer for all your assemblies. Changes are saved only with Apply or Save and Close; Cancel leaves everything as it was. A pencil marks the fields you changed.

TabWhat you set
1. Property ManagementThe properties available as columns: standard and custom iProperties, labels, types, the views that show them, Analytics (Dashboard) and Protected (read-only in the grid, for example fields filled by iLogic).
2-4. Model Data / Structured / Parts Only ViewThe column order of each view.
5. Value ListsLists of values for the cell drop-downs and for rules, and which property uses which list.

Pattern Builder

In a Pattern check, double-click the value (or click ...) to open the Pattern Builder: choose a type (Starts With, Contains, Numeric Only, Part Number Format, Wildcard...), type a value and test it on your own examples before inserting it. No knowledge of regular expressions is needed.

16. Your settings, updates and backups

  • All your settings are stored in one folder: %AppData%\GLR\AdvancedBOMViewer. Do not edit these files by hand.
  • Before replacing or removing any of your files, BOM Viewer saves a dated copy in the Backups folder (the last 10 copies are kept).
  • After an update your settings are kept and the new properties are added automatically; a copy of the previous files is saved in Backups.
  • To start again from scratch use Restore All Factory Settings... in the Configuration Editor (tab 8). Saved presets are kept.
  • If a settings file is damaged, BOM Viewer opens with the factory settings, keeps a copy of the file and tells you once. If only part of a file can be read, the rest is used and the original is kept in Backups.
  • The license is checked each time BOM Viewer opens; you are reminded during the last 30 days before it expires.

17. Typical workflows

"I need a report of all screws and bolts."
  1. Choose Parts Only.
  2. Search (All Columns) for screw;bolt and press Enter.
  3. Click Export..., choose Only rows shown in the grid and Excel.
"Every purchased component must have a Vendor."
  1. In Edit Config, tab 6, add a rule on Vendor with the condition BOM Structure Equals Purchased and the check Required.
  2. Turn on the Checker and tick Show only issues.
  3. Select the rows, type the vendor with Edit properties...: the rows you fix stay in the list until you are done.
"I want to change the material of all the brackets."
  1. Search Part Number Starts With BRK.
  2. Select the rows, right-click the Material cell and choose Edit properties...
  3. Pick the material: masses update at once, and one Undo step reverts everything.
"What changed between two model states?"
  1. Click Compare, choose the Target model state and click ▶.
  2. Tick only Added, Removed and Modified.
  3. Click Export... to send the comparison in Excel or HTML.
"Show me which parts are steel and which are aluminium, in the model."
  1. Open the Dashboard and choose Material.
  2. Tick 3D Heatmap in the panel: the model takes the chart colors.
  3. Click the Steel slice to select its rows and components.
"Group sheet metal parts by material and thickness."
  1. Choose Parts Only and click Group Settings.
  2. Choose Material, then Thickness, then Part Number.
  3. Save the layout with Presets > Save Preset... to reuse it in one click.
