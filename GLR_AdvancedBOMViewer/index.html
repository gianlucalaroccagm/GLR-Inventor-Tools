User Guide: GLR Advanced BOM Viewer

Inspect, Compare, Validate, Edit, Report
Version 6.0 — Complete User Guide

0. What's New in Version 6.0

Version 6.0 introduces a series of powerful enhancements designed to make BOM management faster, more intuitive, and secure.

  • Intelligent Contextual Editing: Right-click any editable cell to update a single row or a multi-selection in one operation. The system performs an upfront editability verification and replaces the menu item with a clear warning if editing is restricted (e.g., ⚠️ Material locked: contains standard assemblies).
  • Formula Protection & Expression Reader: Double-clicking a cell governed by an Inventor formula now loads the underlying expression (e.g., =<Description>) directly into the text box. When performing text casing transformations (UPPERCASE or Title Case), an interactive dialog allows you to exclude formula-based cells and protect your parametric links.
  • Ultra-Compact Tree & Differentiated Icons: The hierarchical tree column has been re-designed with dedicated icons for Part, Sheet Metal, Assembly, Weldment, Virtual, Content Center, iPart/iAssembly Member, AnyCAD Reference, and Group. A vector-drawn overlay ⬆ visually flags promoted components.
  • Smart Export Numbering: Excel and HTML reports now include an optional dynamic numbering column (#). It automatically generates cascading dotted hierarchies in Structured view and sequential flat numbering in flat views. Customize the label, start value, increment, and delimiter, with all settings persisted across sessions.
  • Advanced BOM Compare: Compare the active assembly against another local Model State, iAssembly Member, or a completely external assembly file (.iam). Results are color-coded (Added, Removed, Modified, Unchanged) with interactive status filters and export to Excel or HTML.
  • Real-Time Sync & Non-Modal Operation: The BOM Viewer runs as a fully non-modal window, remaining open while you work directly in the 3D viewport. Structural changes (add, delete, suppress) and Model State switches are automatically reflected in the grid.
  • Multi-Level Grouping & Composite Sorting: Group your BOM by up to three properties simultaneously in a cascading hierarchy. Hold Shift and click multiple column headers to define secondary and tertiary sorting hierarchies, with priority labels (1▲, 2▼) displayed in the headers.
  • Data Protection & Configuration Locks: Mark specific columns as Protected in the Configuration Editor to safeguard fields automatically populated by iLogic rules. Protected columns display a lock icon (🔒) and a light grey background.
  • Live Search & Precise Highlighting: The search engine updates the grid results in real-time as you type. The text highlighting system uses zero-margin character drawing, eliminating artificial spaces and gaps.
  • Revit Category Support: Built-in support for the standard Revit Category property allows seamless CAD/BIM model coordination.
  • Per-Document Layouts: The Viewer remembers column visibilities, custom widths, active filters, and sorting choices individually for each assembly via secure file-specific hashing.

1. Introduction

Welcome to the GLR Advanced BOM Viewer, a powerful add-in for Autodesk Inventor designed to revolutionize how you interact with your Bill of Materials (BOM). This tool goes beyond Inventor's standard capabilities, offering a flexible and highly configurable interface to view, analyze, group, validate, and export your assembly data quickly and efficiently.

1.1 Key Features

  • Powerful Data Grid: View your data in a modern grid featuring sorting, advanced column filters, multi-value global search, and live real-time updates.
  • Total Configuration: You decide which properties to display (iProperties, physical properties, custom properties) and in what order, with per-document layout persistence.
  • Multiple Views:
    • Structured: Analyze your BOM while maintaining the sub-assembly hierarchy, with ultra-compact tree and differentiated icons.
    • Parts Only: Get a complete, flat list of every individual part.
    • From Selection: Instantly inspect only the components you have selected in the Inventor model.
  • Dynamic Grouping: Group identical rows based on any property (Part Number, Material, etc.). Features multi-level grouping (up to 3 criteria) and hierarchical fallback logic to ensure components are always logically aggregated.
  • Interactive Dashboard: Visualize your BOM data with dynamic pie charts. Click on chart segments to instantly select corresponding components in the data grid and the 3D model. Numerical values are mathematically normalized to ensure proportional accuracy.
  • Validation Checker: Define custom rules to automatically highlight invalid or missing data. Non-compliant cells are highlighted in orange with descriptive tooltips.
  • In-Place Editing: Edit iProperties, Material, Appearance, and BOM Structure directly from the grid. Supports dropdown lists (Value Lists), dedicated pickers, and Inventor formula expressions.
  • Advanced BOM Compare: Compare your active assembly against local Model States, iAssembly Members, or external assembly files. Results are color-coded with interactive filters and export capabilities.
  • Custom Presets & Auto-Save: Save and load your favorite view configurations. The tool features an "Auto-Healing" logic that automatically re-enables required properties in the global configuration.
  • Advanced Export: Export your current view to professionally formatted Excel (.xlsx), web-ready HTML, or data-interchange CSV format, including dynamic numbering, component thumbnails, and validation comments.
  • 3D Model Interaction: Selection is synchronized in real-time between the grid and the Inventor 3D model. Partial selections are shown with a grey border, full selections with a blue border.
  • Model States & iAssembly Support: Each Model State and iAssembly Member is treated as a distinct document, ensuring correct mass, properties, and thumbnails.
  • Unit Conversion & Integrity: Length and mass values can be displayed in strict (document) units or converted. In Strict Mode, discordant units within a group are flagged with <Error> to prevent mathematical inconsistencies.

2. Installation and Uninstallation

2.1 Installation

  1. Ensure Autodesk Inventor is closed.
  2. Run the provided setup file (GLR_Advanced_BOM_Viewer.msi).
  3. Follow the simple on-screen instructions. The installation does not require administrator privileges.
  4. First-Time Run Security Alert: The first time you start Autodesk Inventor after installation, you may see an "Add-in Manager Security Alert" because the add-in is not digitally signed by Autodesk. This is normal. Click "Launch Add-in Manager".
  5. Enable the Add-in: In the Add-In Manager window:
    • Find "Advanced BOM Viewer" in the list.
    • Ensure the "Loaded/Unloaded" and "Load Automatically" check boxes are ticked.
    • Click OK.
  6. The add-in is now ready. You will find its launch button in the "Assemble" tab of the ribbon, inside the "GLR Tools" panel.

2.2 Uninstallation

To uninstall this plug-in, first exit Autodesk Inventor. Then, you can either:

  • Re-run the installer (.msi file) and select the "Uninstall" option.
  • OR, go to the Windows Control Panel → Programs and Features (or Apps & Features), find "GLR Advanced BOM Viewer" in the list, and choose "Uninstall".

2.3 Temporarily Disabling the Add-in

You can unload the plug-in without uninstalling it by opening the Add-In Manager in Inventor (Tools tab → Add-Ins) and unchecking the "Loaded/Unloaded" box for the "Advanced BOM Viewer". You may need to restart Inventor for the change to take full effect.

3. User Interface Guide

The main window is divided into several areas: the Top Bar, the Data Grid, the Compare Bar (when active), the Dashboard, and the Status Bar.

3.1 The Top Bar: Your Control Panel

Main Actions

  • Export ▾ – Opens the Export Options window to generate a report. You can choose between Excel (.xlsx), HTML, and CSV formats. In Compare Mode, CSV is automatically disabled to preserve the visual integrity of comparison data. For Excel and HTML exports, the file includes a complete header with report context, your Inventor User Name, and any optional notes you add. Thumbnails are embedded in Excel and HTML.
  • Dashboard – Toggles the visibility of the interactive Dashboard panel at the bottom of the window. Use this to perform visual analysis of your BOM data.
  • Checker – Enables or disables the validation system. When enabled, cells that violate defined rules are highlighted in orange. You can also filter the grid to show only non-compliant rows using the ⚠️ Show only issues checkbox.
  • Compare – Enters or exits BOM Compare mode. When active, the interface switches to a dedicated compare view where you can compare different configurations of your assembly (see Section 3.3).
  • Update Mass – Forces a recalculation of physical properties (Mass, Area, Volume) for all documents currently visible in the grid. The button is enabled only when there are visible documents whose physical properties are not yet cached or are out of date.
  • [↻] (Refresh) – Manually refreshes the data from Inventor, clearing all caches and reloading the current view. Use this when you suspect the view is out of sync.
  • [?] (Help) – Opens this user guide.

Presets Menu

  • Save Current Preset... – Saves the current layout (column order, width, visibility), active filters, grouping, and search criteria as a named preset.
  • ★ Default Template – Applies the global default column layout template to the active document.
  • Manage Saved Presets... – Opens the folder containing your saved presets for renaming or deletion.
  • Redefine Default Template – Saves the current layouts (widths, order, visibility) of ALL three views as the new global default template for new files.
  • Restore Default Template – Resets the default template to factory settings and applies it to the current document immediately.

View Mode

  • Structured: Displays the BOM, keeping sub-assemblies as single rows. Shows the primary assembly row at the top if Show Primary is checked.
  • Parts Only: Displays a flat list of all individual parts.
  • From Selection: An "Inspector" mode. The grid only shows components currently selected in Inventor. Selection highlighting is done with a green highlight set without modifying the Inventor selection set.
  • Show Primary: When checked (only available in Structured view), displays the top-level assembly as the first row, with a dark background and bold text. When the Checker is active, this row is also subject to validation rules.
  • Multi-level: When checked (only available in Structured view), enables the hierarchical tree with expandable/collapsible sub-assemblies. The grouping ComboBox is automatically locked to Part Number to maintain the tree structure integrity.
  • ⚠️ Show only issues: When the Checker is enabled, this checkbox filters the grid to show only rows that contain at least one validation error. The status bar indicates the number of issues found.

Group By

  • Group By ComboBox: Select a property (e.g., Part Number, Material, Stock Number) to group all rows that share the same value. The ComboBox is automatically locked when Multi-level is active.
  • Group Settings Button (⚙): Opens the Multi-level Grouping dialog where you can configure up to 3 grouping criteria in a cascading hierarchy. For example, group by Material → Thickness → Part Number. The button shows a red border when multi-level grouping is active.
  • Reset Button (📥): Resets grouping to Part Number (the default). The button is visible only when grouping is not set to the default.

Advanced Search Bar

Allows powerful and specific filtering of the grid. It consists of three parts:

  • Property Selector: Choose which column to search within, or select (All Columns) for a global search. The list is automatically populated with all visible text columns.
  • Condition Selector: Defines the search type. The available operators adapt dynamically based on the selected column type:
    • Text columns: Contains, Starts With, Ends With, Exact Match, Is Empty
    • Number columns: Equals (=), Greater Than (>), Less Than (<), Greater or Equal (>=), Less or Equal (<=)
    • Date columns: On Date, Before, After
    • Boolean columns: Is True, Is False
  • Search Text Field: Enter your search term. The grid updates in real-time as you type. Press Enter or click the magnifying glass icon (🔍) to apply.
    • Multi-Value Search: Search for multiple values at once by separating them with a semicolon (;). For example, bolt;nut finds all rows containing either "bolt" OR "nut".
    • Blank Values: Use the token <BLANK> to search for empty cells.
    • Numerical Search: Values are automatically extracted from formatted strings (e.g., 15.40 kg is compared as 15.40).
    • Date Search: Supports the current system date format (e.g., dd/MM/yyyy). A calendar popup appears when you click the text box with a Date column selected.
  • Match Navigation (◀/▶): When a search is active, the navigation controls appear. They allow you to cycle through matching rows. Each match is automatically revealed (expanding the tree if necessary in Multi-level mode) and highlighted in the grid.
  • Search Button (🔍/📥): The button icon changes dynamically:
    • 🔍 (Magnifying Glass): No active search, ready to execute.
    • 📥 (Funnel): Search is active. Click to reset the search.

Clear Filters

Instantly clears all applied filters, including search, column filters, grouping, "Show only issues", and (in Compare Mode) all comparison status filters. The button is enabled only when at least one filter is active.

Edit Config

Opens the Configuration Editor (see Section 5). This is where you manage the global property pool, view ordering, value lists, validation rules, and unit settings.

3.2 The Data Grid: Your Workspace

Visual Feedback

  • Filter Border: When any filter (search, column filter, grouping, or "Show only issues") is active, the border of the grid panel turns red. If the "Show only issues" filter is active, the border turns orange, providing an at-a-glance indication that the data is filtered.
  • Row Header Indicator: The row header shows a small triangular marker on the active row when the grid is focused.

Hierarchical Tree (Structured + Multi-level)

  • Expand/Collapse: Click the triangular arrow (▶/▼) next to any sub-assembly row to expand or collapse its children. The tree structure is automatically rebuilt when data changes.
  • Differentiated Icons: Each row displays a dedicated icon based on the component type:
    • Part – Standard part (.ipt)
    • Sheet Metal – Sheet metal part
    • Assembly – Standard assembly (.iam)
    • Weldment – Weldment assembly
    • Virtual – Virtual component
    • Content Center – Content Center part
    • iPart – iPart Member (.ipt)
    • iAssembly – iAssembly Member (.iam)
    • AnyCAD – AnyCAD reference (with grey frame)
    • Group – Grouped component row
  • Promote Badge (⬆): A vector-drawn overlay next to the file icon visually flags promoted components. Hovering over the badge displays a tooltip showing which parent assembly it belongs to (with support for *Varies* in case of multiple parent groupings).
  • Cloud Frame: AnyCAD reference components are displayed with a thin grey frame around their icon.

Sorting

  • Single Column Sort: Click any column header to sort the data in ascending or descending order. The column header shows a triangle (▲/▼) indicating the sort direction.
  • Multi-Column Sort: Hold Shift and click additional column headers to define secondary and tertiary sorting hierarchies. Sorted columns display priority labels (e.g., 1▲, 2▼, 3▲) directly in the header.
  • Natural Sorting: Sorting uses a natural alphanumeric algorithm (e.g., Part2 comes before Part10).
  • Tree-Aware Sorting (Multi-level): When Multi-level is active, sorting preserves the hierarchical structure. The tree is sorted recursively, with each level of the tree sorted independently while maintaining parent-child relationships.

Column Filters (∇ / 📥)

  • Click the funnel icon (∇) in a column header to open a filter menu. The menu shows a list of all unique values in that column.
  • Select the desired values from the list and click "Apply". The icon changes to a filled funnel (📥) to indicate that a filter is active on that column.
  • Filters support multi-selection and the <BLANK> token for empty values.
  • Click "Clear" to remove the filter from that column.

Selection Synchronization

  • Selecting rows in the grid automatically selects the corresponding occurrences in Inventor.
  • Selecting components in Inventor highlights the corresponding rows in the grid.
  • When a row contains multiple occurrences but only a subset is selected in Inventor, the row border becomes grey (partial selection). When all occurrences are selected, the border is blue (full selection).
  • In From Selection mode, the grid does not modify the Inventor selection set; instead, it uses a green highlight set to visually indicate the selected components.
  • The current cell is highlighted with a cyan border. In Multi-level mode, all cells in the same column of selected rows show a subtle cyan overlay for easy visual tracking.

Inline Editing

Many cells are editable directly in the grid. Editable properties include:

  • Design Tracking, Summary Information, Document Summary Information, and User Defined iProperties.
  • Material (for part documents and virtual components).
  • Appearance (for part documents; also provides a Clear Override option to reset to the material-based appearance).
  • BOM Structure (Normal, Phantom, Purchased, Reference, Inseparable).
  • Revit Category (for CAD/BIM interoperability).
  • When a group of rows (<Varies>) is edited, you will be prompted to confirm overwriting all files in the group.

Value Lists (Dropdowns)

If a property has been associated with a Value List (see Section 5.3), a ▼ button appears when editing that cell. Click it to select a value from a filterable dropdown. This works for standard iProperties, custom user-defined properties, Material, Appearance, BOM Structure, and Revit Category.

Inventor Formulas

  • Reading Formulas: Double-clicking a cell that contains an Inventor formula (e.g., =<Description>) loads the underlying expression into the text box instead of the evaluated static text.
  • Writing Formulas: Enter a value starting with = (e.g., =<PartNumber>) to write a formula expression. The system evaluates it and displays the result in the cell while preserving the formula.
  • Formula Protection: When performing text casing transformations (UPPERCASE or Title Case) on a selection that contains formula-based cells, an interactive dialog allows you to exclude those cells and protect your parametric links.
  • Anti-Overwrite Safeguard: When performing a Bulk Update on a heterogeneous selection, the input box is pre-populated with <Varies>. If you click OK without modifying this text, the system intercepts the action and aborts the save.

Context Menus (Right-Click)

On a Column Header:

  • Remove Column: Hides the selected column from the current view. The column can be re-added later.
  • Add Column... Opens a dialog to select a property from the global pool and add it as a new column to the current view. The column is inserted after the clicked column.
  • Edit Column Configuration... Provides a convenient shortcut to open the full Configuration Editor.
  • Add/Edit/Clear Filter: Opens the column filter menu.
  • Sort Ascending/Descending: Sets or adds to the multi-column sort.
  • Clear All Sorting: Removes all active sort keys.

On a Grid Row or Cell:

  • Copy: Copies the value of the clicked cell (or all selected cells in the same column) to the clipboard. If the cell contains a formula, the raw expression is copied.
  • Paste: Pastes the clipboard content into the clicked cell (or across multiple selected cells). Supports both single-value replication and staggered multi-value paste.
  • Edit properties... Opens an input dialog for the selected property. Supports:
    • Text fields: Free text input with automatic formula detection.
    • Number fields: Numeric validation with decimal separator auto-correction.
    • Date fields: Calendar popup with "Clear" button.
    • Boolean fields: True/False dropdown.
    • List fields: Filterable dropdown (Material, Appearance, BOM Structure, Revit Category, Value Lists).
  • Capitalize: Converts the selected text to UPPERCASE. When applied to a group (<Varies>), propagates the transformation to all components in the group.
  • Title Case: Converts the selected text to Title Case. When applied to a group (<Varies>), propagates the transformation to all components in the group.
  • Open Selected: Opens the component file in Inventor (available for single-row selection only; disabled for groups, virtual components, and cloud-referenced files).
  • Show Selected / Hide Selected / Isolate Selected: Controls visibility of the corresponding components in the model.
  • Clear Selection: Deselects all rows in the grid and all components in the model.
  • Expand All Children / Collapse Sub-assembly: Available in Multi-level mode for rows that have children.
  • iProperties... Opens the native Inventor iProperties dialog for the selected component(s).

Keyboard Shortcuts

  • Ctrl+C: Copy the current cell value (or all selected values in the same column).
  • Ctrl+V: Paste from clipboard into the current cell (or across multiple selected cells).
  • Delete: Clear the current cell value. Protected cells (e.g., Appearance, Material, BOM Structure, Revit Category) cannot be deleted.
  • ↑/↓: Navigate rows while preserving the current column.
  • ←/→: Navigate columns while preserving the current row.
  • Shift+Click (column header): Add to multi-column sort.
  • Enter: In edit mode, confirms the edit and commits the change.

Recognition of BOM Overrides

  • Quantity Overrides: Quantities that have been manually overridden in Inventor (displayed in blue in the standard BOM) are shown in the italic underlined style in the grid.
  • BOM Structure Overrides: When a component's BOM Structure is changed (e.g., from Normal to Reference), the cell displays the new value in italic and, when hovered, shows a tooltip indicating the Native Value (e.g., Default: Normal).

Unit Integrity <Error>

In Strict Mode, if a group contains discordant units (e.g., a mix of mm and inches, or kg and lb), the total columns will display <Error>. This is a safety feature to prevent incorrect mathematical sums. To resolve this, simply enable a conversion mode in Tab 7 of the Configuration Editor to normalize all values.

Validation Highlighting

When the Checker is enabled:

  • Cells that fail validation rules are shown with an orange background and bold black text.
  • Hovering over an invalid cell displays a tooltip with the error message (e.g., "Part Number is required").
  • Rows that contain any invalid cell are considered non-compliant. You can filter to show only these rows using the ⚠️ Show only issues checkbox.

3.3 The Compare Mode

BOM Compare mode allows you to visually compare different configurations of your assembly. The Compare button in the Top Bar toggles this mode.

Entering Compare Mode

  • Click the Compare button. The interface switches to a dedicated compare view.
  • The current active configuration (Model State or iAssembly Member) becomes the Baseline (State A).
  • The Dashboard and Checker are automatically disabled during Compare to ensure a clean comparison environment.

Selecting a Target

  • Local Model States: Select from the dropdown list of available Model States of the active assembly.
  • Local iAssembly Members: Select from the dropdown list of available Members in the iAssembly Factory table.
  • External Assembly: Select <Browse external IAM...> and choose an assembly file (.iam) on disk. The tool opens it silently in the background and reads its configurations.
  • The target selection is displayed in the compare bar.

Executing a Comparison

  • Click the Play (▶) button to execute the comparison.
  • The tool scans both configurations in RAM and calculates the differences.
  • Results are displayed in the grid with semantic colors.
  • The Play button turns into a ✓ when the comparison is up-to-date.

Comparison Results

  • 🔴 Removed (Red & Strikethrough): Components that existed in the Baseline but are missing in the Target.
  • 🔵 Added (Blue): Components newly inserted in the Target.
  • 🔵 Modified (Bold Blue/Cyan): Components present in both but with changed properties. Hovering over a modified cell displays the previous baseline value in a tooltip.
  • ⚫ Unchanged (Grey): Components that remained identical between both versions.

Interactive Status Filters

Use the checkboxes in the compare bar to instantly filter and isolate specific categories:

  • Added – Show only added components.
  • Removed – Show only removed components.
  • Modified – Show only modified components.
  • Unchanged – Show only unchanged components.

Compare Export

  • Export to Excel (.xlsx) or HTML (.html) preserves all semantic colors and comments.
  • In Excel, modified cells contain comments showing the previous baseline values.
  • CSV export is automatically disabled in Compare Mode to protect the visual integrity of your comparison data.

Exiting Compare Mode

  • Click the Exit Compare button (the Compare button now shows "Exit Compare").
  • The tool restores the Baseline configuration in Inventor.
  • The Dashboard and Checker are re-enabled, and the standard view is restored.
  • The AutoSave mechanism protects your ferial layout: if you close the window using the Windows "X" button while Compare Mode is active, the system bypasses AutoSave to prevent the temporary comparison layout from overwriting your standard settings.

3.4 The Status Bar: Real-Time Information

The bar at the bottom of the window provides contextual status messages, such as:

  • Number of rows displayed.
  • Current filter summary.
  • Number of search matches found.
  • Number of validation issues detected.
  • Warning messages (e.g., "View out of date").
  • In Compare Mode: detailed row change information when a row is selected.

The status bar also displays a live summary of selected rows, the active cell value, and any formula expression associated with the cell.

3.5 The Dashboard: Visual Analysis

The Dashboard provides an interactive graphical representation of your Bill of Materials data. It is directly linked to the data visible in the grid, respecting all active filters and groupings.

Activating the Dashboard

Click the Dashboard button in the top bar. A new panel will appear below the data grid. The splitter position is remembered between sessions.

Analyze Property

Use this dropdown to select the property you want to visualize. The list is organized to show categorical properties (like Material, BOM Structure) first, followed by numerical properties (like Total Mass, Total Quantity).

Mathematical Truth

For numerical properties, values are automatically normalized to a consistent unit (e.g., all masses in kg, all lengths in cm) before being displayed. A 1 kg part will always look twice as large as a 0.5 kg part, regardless of whether the grid displays kg, lb, or grams.

Interactive Selection

Click on a slice of the pie chart to:

  • Instantly select all corresponding rows in the data grid.
  • Instantly select all corresponding components in the Inventor 3D model.

This allows you to quickly identify and locate components based on their properties (e.g., "select all Steel parts", "find the heaviest components").

Show Labels

The Show Labels checkbox toggles the visibility of value labels on the pie chart. When unchecked, the chart displays only the colored slices for a cleaner view.

Smart Aggregation

If the number of categories exceeds the limit (8 for pie), the chart automatically aggregates the smallest categories into an "Others" slice.

4. Typical Workflows (Use Cases)

"I want a report of all screws and bolts."
  1. Select the Parts Only view.
  2. In the search bar, type screw;bolt and press Enter.
  3. Click Export... and choose Excel or HTML.
"I want to find all 'Purchased' components missing the 'Vendor' property."
  1. Select the Structured view.
  2. Filter the BOM Structure column to show only "Purchased".
  3. Define a Validation Rule on the Vendor property with a condition: BOM Structure Equals "Purchased" → Check: Required.
  4. Enable the Checker. Invalid cells will appear in orange.
  5. Check ⚠️ Show only issues to isolate the problematic rows.
"I want to identify the heaviest components, regardless of their document units."
  1. Click the Dashboard button to open the analysis panel.
  2. From the Analyze Property dropdown, select Total Mass.
  3. The chart will immediately show the distribution. Thanks to internal normalization, components using 'lb' and 'kg' are compared correctly.
  4. Click on the largest slice to select and highlight the heaviest component(s) in both the grid and the 3D model.
"I want to compare two design revisions of my assembly."
  1. Click the Compare button in the Top Bar.
  2. Select the target Model State from the dropdown.
  3. Click Play (▶) to run the comparison.
  4. Use the checkboxes (Added, Removed, Modified, Unchanged) to isolate specific categories.
  5. Click Export to generate a comparison report in Excel or HTML.
  6. Click Exit Compare to return to the standard view.
"I want to group sheet metal parts by thickness and material."
  1. Select the Parts Only view.
  2. Click the Group Settings (⚙) button next to the Group By dropdown.
  3. In the multi-level grouping dialog, add Material as the first key and Thickness as the second key.
  4. Click OK. The BOM is now grouped by Material → Thickness.
  5. Use the 📥 reset button to return to Part Number grouping.
"I need a documented report for a supplier, including my notes and numbered rows."
  1. Prepare the data using filters and grouping.
  2. Click Export... to open the Export Options dialog.
  3. In the Include numbering section, customize the label, start value, increment, and delimiter as needed.
  4. In the Notes & Comments field, add your remarks (e.g., "BOM for quotation QF-1234").
  5. Choose Excel (.xlsx) or HTML format. The exported file will include a header with your notes, the view context, active filters, and your User Name.
"I want to ensure all Part Numbers follow a standard format and are Uppercase."
  1. Open Edit Config and go to the Validation Rules tab.
  2. Select the Part Number property.
  3. Add a Check of type Pattern (Regex: ^[A-Z]{3}-\d{5}$) and a Check of type Upper Case.
  4. Save and enable the Checker. Cells that do not match the format or casing will turn orange.

5. Advanced Configuration (Edit Config)

The Configuration Editor gives you complete control over the information displayed, validation rules, value lists, and unit preferences. It is organized into 7 tabs.

5.1 Tab 1: Property Management

This is the main tab where you define the "pool" of all properties available to the add-in.

Main Grid

  • Enabled: A property must be checked here to be available in any view. Disabling a property that is used in validation rules will automatically disable those rules.
  • Label: The name that will appear in the column header.
  • Data Source: Defines the origin of the property:
    • Standard: System properties (Design Tracking, Summary Info, Document Summary Info).
    • Custom: User Defined iProperties.
  • Property: For standard properties, choose from a list; for custom properties, type the exact iProperty name.
  • Data Type: For custom properties, select the appropriate type (Text, Number, Date, Boolean).
  • Use in...: Check the boxes to determine in which views the property will be visible by default.
  • Analytics: Check this box to make the property available for analysis in the Dashboard. Only properties that are meaningful to visualize (like Material, Mass, Quantity) should be enabled.
  • Protected: Check this box to mark the column as read-only in the grid. Protected columns display a lock icon (🔒) and a light grey background. This is designed to safeguard fields automatically populated by iLogic rules.

Special System Properties

  • Protected Properties: Some properties like FileName, PartNumber, Thumbnail, Quantity, and physical properties (ItemMass, TotalMass, etc.) are protected and cannot be disabled or deleted.
  • Model State: When enabled, displays the current Model State name (e.g., [Primary], coarse). It is read-only and protected.

Adding a New Property

  • Click Add New Property. The new property is created as a "Standard" property by default.
  • Select the Data Source (Standard or Custom) in the Details panel.
  • For Standard properties, select the desired property from the dropdown.
  • For Custom properties, type the exact iProperty name (must match the iProperty name in Inventor).
  • Set the Data Type (Text, Number, Date, Boolean) as needed.
  • Assign a Label and check the views where it should appear.
  • The property is saved when you click Save or Save and Close.

Deleting a Property

5.4 Tab 6: Validation Rules

Validation rules allow you to define automatic checks on the data entered in the cells. When the Checker is enabled (main toolbar button), cells that violate a rule are highlighted in orange and show an error message on mouse hover.

Rule Structure

A rule consists of two main parts:

  • Conditions (optional): Determine when the rule should be applied. If no conditions are specified, the rule always applies to the target property.
  • Checks (mandatory): Define what makes the value non-compliant. Each rule must have at least one check.

5.4.1 Conditions – "When to apply the rule"

Conditions allow you to restrict validation to specific contexts. For example, you may want to check that a material is present only for "Sheet Metal" components.

Each condition compares the value of another property (not the target) using an operator. Multiple conditions can be combined using the logical operators AND (all must be true) or OR (at least one true).

Operators available for conditions:

  • Equals / Not Equals – case-insensitive equality.
  • Is Empty / Is Not Empty – checks whether the property is empty.
  • Contains / Not Contains – checks for the presence of a substring.
  • Starts With / Ends With – checks prefix/suffix.
  • In List – checks if the value belongs to a Value List (see Section 5.3).

5.4.2 Checks – "What makes the value invalid"

Checks are the actual validations on the target property's value. A rule can have multiple checks: all of them must pass for the cell to be considered valid.

Available check types:

  • Required – the value cannot be empty or whitespace only.
  • Min Length / Max Length – enforces a minimum/maximum number of characters.
  • In List / Not In List – the value must (or must not) belong to a predefined Value List.
  • Pattern – checks that the value matches a regular expression (Regex). The ... button opens the Pattern Builder to create the regex visually.
  • Upper Case / Lower Case – forces the value to be entirely uppercase or lowercase.

Error Messages

Each check can have a custom error message. If left empty, the system automatically generates a descriptive message (e.g., "Part Number is required."). Error messages are displayed in the grid when the Checker is enabled.

Managing Rules in the Editor

The three-panel layout:

  • Left Panel: List of properties with their rule status and rule count.
  • Center Panel: List of rules for the selected property.
  • Right Panel: Rule editor (conditions + checks).

Status Icons in Properties Grid (Left Panel):

  • ● (Green Dot): All rules for this property are active and healthy.
  • ◐ (Half Green Dot): Some rules are active and healthy, some are disabled.
  • ○ (Empty Circle): All rules are manually disabled.
  • ⚪ (Grey Circle): No rules defined for this property.
  • ⚠ (Warning): Some rules have issues (no checks, broken list references).
  • 🔴 (Red Circle): Property is disabled in Tab 1.

Status Icons in Rules Grid (Center Panel):

  • ● (Green Dot): Rule is active and valid (all references exist).
  • ⚠ (Warning): Rule has issues (no checks, broken list references).
  • 🔴 (Red Circle): Rule is manually disabled.
  • ❓ (Question Mark): Unsaved draft rule.

Creating a Rule:

  • Select a property in the left panel.
  • Click New Rule in the center panel.
  • Enter a name for the rule.
  • Add conditions (optional) and checks (required).
  • Click Save Rule to persist it.
  • The rule is immediately active (if Enabled) and will be evaluated by the Checker.

Editing a Rule:

  • Select a rule in the center panel. Its details appear in the right panel.
  • Modify conditions, checks, or the Enabled state.
  • Click Save Rule to persist changes.
  • Click Cancel to discard changes and revert to the saved version.

Deleting a Rule:

  • Select a rule in the center panel.
  • Click Delete and confirm.

Practical Examples

Example 1 – Standardized Naming (Pattern + Case)
Goal: "Descriptions must start with 'FRAME-', be all uppercase, and follow a numeric pattern XXXX."
  • Check 1: Starts With: "FRAME-"
  • Check 2: Upper Case
  • Check 3: Pattern (Regex): ^FRAME-\d{4}$
Example 2 – Conditional Procurement Data
Goal: "If a part is 'Purchased', it MUST have a 'Vendor' and 'Stock Number'."
  • Rule A (Vendor): Condition: BOM Structure Equals "Purchased" → Check: Required.
  • Rule B (Stock Number): Condition: BOM Structure Equals "Purchased" → Check: Required.
Example 3 – List Validation
Goal: "Material must be one of the approved values."
  • Create a Value List called "ApprovedMaterials" with values: Steel, Aluminum, Stainless Steel.
  • In Tab 5, associate the Material property with the "ApprovedMaterials" list.
  • In Tab 6, create a rule on Material with Check: In List (select "ApprovedMaterials").

5.5 Tab 7: Unit Settings

Control how physical quantities (Length and Mass) are displayed in the grid. These settings are global and remembered between sessions.

Length Mode

  • Strict – displays values in the original unit of each document (e.g., mm, cm, in).
  • ToDocumentUnit – converts all length values to the unit of the top-level assembly document (e.g., if the assembly is in mm, all lengths are shown in mm).
  • ToCustomUnit – converts all length values to a user-defined unit (select from mm, cm, m, in, ft).

Mass Mode

Same logic as Length, with units kg, g, slug, lb.

Decimal Places

Choose the number of decimal places (0 to 8) for Length, Mass, Area, and Volume. The preview shows the formatting (e.g., "3,123" for 3 decimals).

How Unit Conversion Works

  • Unit conversion applies to columns such as Base Quantity, Total Quantity, Item Mass, Total Mass, Item Area, Item Volume, etc.
  • The Dashboard also uses normalized units for consistent chart proportions.
  • In Strict Mode, discordant units within a group are flagged with <Error> to prevent incorrect mathematical sums.
  • When a unit conflict is detected in a group, a tooltip indicates the conflicting units (e.g., "Mixed unit or incompatible type detected in this group: mm / in").
